# Breast Cancer Prediction Project

This project contains a Jupyter notebook for building a breast cancer classification model using the Breast Cancer Wisconsin dataset.

## Project Files

- `Breast_Cancer_Prediction_test.ipynb` - notebook with data loading, cleaning, visualization, preprocessing, training, and evaluation.
- `Cancer_Data.csv` - dataset used in the notebook.
- `requirements.txt` - Python dependencies for the project.

## Goal

The goal of the notebook is to predict whether a tumor is benign or malignant based on the available measurements in the dataset.

## Workflow

1. Load the dataset.
2. Explore the data and inspect missing values.
3. Clean the data by removing unnecessary columns.
4. Visualize the target distribution and feature relationships.
5. Preprocess the data by encoding labels and scaling features.
6. Train a Logistic Regression model.
7. Evaluate the model using accuracy, a classification report, and a confusion matrix.

## Requirements

Install the dependencies listed in `requirements.txt`.

## How to Run

1. Open the notebook `Breast_Cancer_Prediction_test.ipynb` in VS Code or Jupyter.
2. Make sure the Python environment has the required packages installed.
3. Run the cells from top to bottom.
## Output

The notebook produces:

- Basic dataset inspection output
- Plots for diagnosis distribution, feature comparison, and correlation
- Model accuracy and classification report
- A confusion matrix plot
